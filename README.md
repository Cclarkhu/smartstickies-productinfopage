# 🧠 Smart Stickies — AI Product Info Page (RAG Prototype)

This prototype uses Retrieval-Augmented Generation (RAG) to generate product information pages for retail items using LangChain, OpenAI's GPT, and FAISS vector search. Built for the Smart Stickies internship project.

---

## 🚀 Features

- 🔍 Query product documentation using natural language
- 🧠 RAG pipeline with FAISS + OpenAI Chat model
- 🖥️ Streamlit UI for interactive demos
- 🔐 Pickle-protected loading (safe by default)

---

## 🧰 Tech Stack

- `langchain`
- `langchain-community`
- `langchain-openai`
- `faiss-cpu`
- `streamlit`
- `openai`
