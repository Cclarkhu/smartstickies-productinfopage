
# Smart Stickies Product Info Page (O3 Prototype)

This is a Streamlit web app that generates marketing copy for Smart Stickies using the O3 (GPT-3.5 Turbo) model from OpenAI.

## 🚀 Quick Start

1. **Clone this repository or download as ZIP:**
   ```
   git clone https://github.com/aarrushm/smartstickies-productinfopage.git
   ```
   *(If you downloaded as ZIP, unzip it and open the folder.)*

2. **Navigate to the project folder:**
   ```
   cd smartstickies-productinfopage
   ```
   *(Or adjust the folder name if it’s different after unzipping.)*

3. **Switch to the O3 prototype branch:**
   ```
   git checkout o3-first-draft
   ```

4. **Install the required Python packages:**
   ```
   pip3 install -r requirements.txt
   ```
   *(Use `pip3` on Mac; `pip` works too if you have only one Python installed.)*

5. **Run the Streamlit app:**
   ```
   streamlit run smart_stickies_app.py
   ```

6. **Paste your OpenAI API key** into the app when prompted.

## 📝 What Does This App Do?

- Displays a Smart Stickies product info page with image, price, and key features.
- Lets you generate dynamic marketing copy (tagline and benefits) using the O3 (gpt-3.5-turbo) model.
- Shows token usage and latency for each AI call (for bake-off/model comparison).

## ✅ Requirements

- Python 3.8 or newer (macOS usually comes with Python; you can update at https://www.python.org/downloads/)
- [OpenAI API key](https://platform.openai.com/account/api-keys)
- Internet connection
